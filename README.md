# 대한민국 행정구역 지도 (시도 · 시군구 · 읍면동)

PPT에 넣을 지도를 바로 뽑아 쓰기 위한 대한민국 행정구역 경계 SVG 묶음과 웹 도구입니다.

- 시도 16 · 시군구 256(일반구 포함) · 읍면동 3,559개 경계, **2026.10.01 기준** (전남광주통합특별시 반영)
- 지역 하나를 고르면 **그 지역을 360° 둘러싼 이웃 지역**(맞닿은 곳, 또는 두 겹)을 함께 그립니다.
  예: 대전광역시 → 세종시 · 청주시 · 보은군 · 옥천군 · 금산군 · 논산시 · 계룡시 · 공주시
- **SVG / PNG / PPTX**로 저장. PPTX는 지역 하나하나가 PowerPoint 도형이라 색·선을 바로 바꿀 수 있습니다.

## 1. 웹 도구 (`web/`)

`web/index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없습니다.

| 기능 | 설명 |
| --- | --- |
| 지역 찾기 | `대전`, `유성구`, `정자동`처럼 일부만 입력해도 시도·시군구·읍면동을 찾습니다 |
| 주변 지역 | 표시 안 함 / 맞닿은 곳 / 두 겹 |
| 주변 지역 단위 | 시도 / 시군구 / 읍면동 — 대상이 대전광역시(시도)여도 주변은 시군구 단위로 볼 수 있습니다 |
| 대상 안쪽 나누기 | 대상 안을 시군구·읍면동으로 나눠 그립니다 (예: 수원시를 읍면동으로) |
| 일반구 나누기 | 끄면 수원시·청주시처럼 구가 있는 시를 한 덩어리로, 켜면 장안구·권선구…로 |
| 지도 클릭 | 지도 위 지역을 누르면 그 지역이 새 대상이 됩니다 |
| 색 · 글자 · 비율 | 색 조합 5종 + 직접 지정, 주변 지역 색 다르게(이웃끼리 겹치지 않게), 16:9 · 4:3 · 1:1 |
| 목록 복사 | "대전광역시 주변 8곳: 세종시(세종), 청주시(충북), …" 형태로 복사 |

### PPT에서 쓰는 법

- **PPTX** (추천): 16:9 슬라이드 한 장에 지도가 들어 있습니다. 지역마다 이름이 붙은 도형이라 선택 창(Alt+F10)에서 골라 색을 바꾸거나 지울 수 있습니다.
- **SVG**: PowerPoint 2019 / Microsoft 365에서 `삽입 → 그림`으로 넣은 뒤 `마우스 오른쪽 → 도형으로 변환`하면 지역별 도형으로 풀립니다.
- **PNG**: 4000px 안팎 고해상도, 기본 투명 배경 (흰 바탕 옵션 있음).

## 2. 미리 만든 SVG (`svg/`)

웹 도구를 열지 않아도 바로 쓸 수 있게 495장을 미리 만들어 두었습니다.

| 폴더 | 내용 | 예 |
| --- | --- | --- |
| `01_전국` | 전국 시도 / 시군구 / 시군구(일반구) | `전국_시도.svg` |
| `02_시도` | 시도 하나를 시군구로 나눈 지도 (16장) | `대전광역시.svg` |
| `03_시도_주변` | 시도 + 맞닿은 시군구 | `대전광역시_주변.svg` |
| `04_시군구` | 시군구 하나를 읍면동으로 나눈 지도 | `경기_수원시.svg` |
| `05_시군구_주변` | 시군구 + 맞닿은 시군구 | `대전_유성구_주변.svg` |

SVG 안의 지역 `<path>`에는 `id="대전광역시_유성구"`처럼 이름이 붙어 있고, 그룹은 `배경 / 주변 / 대상 / 대상_내부 / 시도경계 / 지명`으로 나뉘어 있습니다.

## 3. 데이터 다시 만들기 (`scripts/`)

행정구역이 바뀌면 최신 경계로 다시 만들 수 있습니다.

```bash
pip install -r scripts/requirements.txt
python scripts/build_data.py            # 최신 시점 (특정 시점: python scripts/build_data.py 20261001)
node scripts/export_svgs.js             # svg/ 전체 다시 만들기 (특정 지역만: node scripts/export_svgs.js 대전)
```

- `build_data.py`: 경계를 받아 `web/data/base.js`(시도·시군구), `web/data/emd.js`(읍면동)로 저장하고,
  모든 단위 조합(시도↔시군구↔읍면동)의 **인접 관계를 미리 계산**합니다. 50m 이내로 맞닿으면 이웃으로 봅니다.
  바다 건너 섬(제주, 울릉 등)은 맞닿은 지역이 없습니다.
- `export_svgs.js`: 웹 도구와 같은 렌더러(`web/render.js`)로 `svg/`를 만듭니다.

좌표는 EPSG:5179(UTM-K)를 10m 격자로 옮긴 값이라 지도가 위아래로 눌리지 않습니다.
