# 대한민국 행정구역 지도 (시도 · 시군구 · 읍면동)

PPT에 넣을 지도를 바로 뽑아 쓰기 위한 대한민국 행정구역 경계 SVG 묶음과 웹 도구입니다.

- 시도 16 · 시군구 256(일반구 포함) · 읍면동 3,559개 경계, **2026.10.01 기준** (전남광주통합특별시 반영)
- 지역 하나를 고르면 **그 지역을 360° 둘러싼 이웃 지역**(맞닿은 곳, 또는 두 겹)을 함께 그립니다.
  예: 대전광역시 → 세종시 · 청주시 · 보은군 · 옥천군 · 금산군 · 논산시 · 계룡시 · 공주시
- 시도·시군구·읍면동 중 단위를 정하고 **원하는 지역만 골라** 한 장으로 만들 수 있습니다 (고르지 않은 지역은 흐리게 두거나 빼기).
- 지역 이름은 **모두 넣기 / 모두 빼기 / 고른 것만** 중에서 고릅니다.
- **17개 시도(광주·전남 나눔)** 로도 볼 수 있습니다. 데이터 기준 시점(2026.10.01)에는 두 곳이 전남광주통합특별시로 합쳐져 있습니다.
- **타일 지도**(네모·육각): 지역 하나를 같은 크기 칸 하나로 바꿔 실제 위치에 가깝게 배치합니다.
- **데이터로 색칠**: 엑셀에서 "지역명 · 값" 두 칸을 복사해 붙여넣으면 숫자는 단계별로, 글자는 분류별로 칠하고 범례를 만듭니다.
- **색 그룹 · 범례 · 제목**: 본사·지사처럼 그룹을 만들어 지도에서 눌러 칠하고, 범례와 제목·부제·출처를 지도에 넣습니다.
- **작업 저장 · 불러오기 · 되돌리기**, 이미지 클립보드 복사(PPT에 바로 붙여넣기).
- **SVG / PNG / PPTX**로 저장. PPTX는 지역 하나하나가 PowerPoint 도형이라 색·선을 바로 바꿀 수 있습니다.

## 1. 웹 도구 (`web/`)

`web/index.html`을 브라우저로 열면 됩니다. 설치나 서버가 필요 없습니다.

지도 방식은 세 가지입니다.

| 방식 | 하는 일 |
| --- | --- |
| 주변 지역 보기 | 지역 하나를 고르면 그 지역과 맞닿은 지역을 함께 그립니다 |
| 영역 직접 고르기 | 단위(시도 / 시군구 / 읍면동)를 정하고 지도에서 지역을 눌러 넣고 뺍니다. 그림 범위는 고른 영역에 맞추거나 전국 전체로 둘 수 있고, 고르지 않은 지역은 빼 버릴 수도 있습니다. "이 시도 전부 넣기"로 한 시도의 시군구를 한 번에 넣을 수 있습니다 |
| 전국 | 전국을 시도 / 시군구 / 읍면동 단위로 그립니다 |

| 기능 | 설명 |
| --- | --- |
| 지역 찾기 | `대전`, `유성구`, `정자동`처럼 일부만 입력해도 시도·시군구·읍면동을 찾습니다 |
| 주변 지역 | 표시 안 함 / 맞닿은 곳 / 두 겹 (주변 지역 보기 방식) |
| 주변 지역 단위 | 시도 / 시군구 / 읍면동 — 대상이 대전광역시(시도)여도 주변은 시군구 단위로 볼 수 있습니다 |
| 대상 안쪽 나누기 | 대상 안을 시군구·읍면동으로 나눠 그립니다 (예: 수원시를 읍면동으로) |
| 일반구 나누기 | 끄면 수원시·청주시처럼 구가 있는 시를 한 덩어리로, 켜면 장안구·권선구…로 |
| 지도 클릭 | 지도 위 지역을 누르면 그 지역이 새 대상이 됩니다 |
| 지역 이름 | 모두 넣기 / 모두 빼기 / 고른 것만. "고른 것만"에서는 지도를 누르거나 아래 목록에서 이름을 하나씩 켜고 끕니다 |
| 배치 | **실제 지도** · **벌려 놓기**(조각들을 중심에서 바깥으로 띄움) · **네모 타일** · **육각 타일** |
| 데이터로 색칠 | "데이터 · 범례" 탭에 엑셀 표를 붙여넣기. 숫자는 3~7단계(같은 개수씩 / 같은 간격), 색 7종(색각 친화 포함), 이름 아래 값 표시. "대전 중구"처럼 시도를 붙이면 같은 이름(중구 등)도 구분합니다 |
| 색 그룹 · 범례 | 그룹을 만들고 지도에서 눌러 칠하기, 범례 제목·위치(네 모서리) |
| 제목 · 출처 | 제목·부제와 출처를 지도 그림 안에 넣기 (SVG·PNG·PPTX 모두) |
| 작업 관리 | 되돌리기·다시 하기(Ctrl+Z / Ctrl+Shift+Z), 작업 파일(.json) 저장·불러오기, 브라우저에 자동 저장, 이미지 복사 |
| 하나씩 꾸미기 | 지도 위 "하나씩 꾸미기"를 고른 뒤 지역을 누르면 그 지역만 색·이름을 바꾸거나 이름을 숨길 수 있고, 끌어서 위치를 옮길 수 있습니다. 저장한 SVG·PNG·PPTX에 그대로 들어갑니다 |
| 17개 시도 | "광주·전남 나눠 보기"를 켜면 광주광역시·전라남도로 나눠 그립니다 |
| 스타일 · 비율 | 색 테마 6종(코발트·코랄·에메랄드·라벤더·먹·미드나잇) + 직접 지정, 고른 지역 그림자, 이웃끼리 색 다르게, 16:9 · 4:3 · 1:1 |
| 목록 복사 | "대전광역시 주변 8곳: 세종시(세종), 청주시(충북), …" 형태로 복사 |

### PPT에서 쓰는 법

- **PPTX** (추천): 16:9 슬라이드 한 장에 지도가 들어 있습니다. 지역마다 이름이 붙은 도형이라 선택 창(Alt+F10)에서 골라 색을 바꾸거나 지울 수 있습니다.
- **SVG**: PowerPoint 2019 / Microsoft 365에서 `삽입 → 그림`으로 넣은 뒤 `마우스 오른쪽 → 도형으로 변환`하면 지역별 도형으로 풀립니다.
- **PNG**: 4000px 안팎 고해상도, 기본 투명 배경 (흰 바탕 옵션 있음).

## 2. 미리 만든 SVG (`svg/`)

웹 도구를 열지 않아도 바로 쓸 수 있게 521장을 미리 만들어 두었습니다.

| 폴더 | 내용 | 예 |
| --- | --- | --- |
| `01_전국` | 전국 시도(16개·17개) / 시군구 / 시군구(일반구) | `전국_시도_17개.svg` |
| `02_시도` | 시도 하나를 시군구로 나눈 지도 (광주·전라남도 포함 18장) | `대전광역시.svg` |
| `03_시도_주변` | 시도 + 맞닿은 시군구 | `대전광역시_주변.svg` |
| `04_시군구` | 시군구 하나를 읍면동으로 나눈 지도 | `경기_수원시.svg` |
| `05_시군구_주변` | 시군구 + 맞닿은 시군구 | `대전_유성구_주변.svg` |
| `06_타일` | 타일 지도: 전국 시도(16·17개)·시군구(네모·육각), 시도별 시군구 육각 | `서울특별시_시군구_육각.svg` |

SVG 안의 지역 `<path>`에는 `id="대전광역시_유성구"`처럼 이름이 붙어 있고, 그룹은 `배경 / 주변 / 대상 / 대상_내부 / 시도경계 / 지명`으로 나뉘어 있습니다.

## 3. 데이터 다시 만들기 (`scripts/`)

행정구역이 바뀌면 최신 경계로 다시 만들 수 있습니다.

```bash
pip install -r scripts/requirements.txt
python scripts/build_data.py            # 최신 시점 (특정 시점: python scripts/build_data.py 20261001)
node scripts/export_svgs.js             # svg/ 전체 다시 만들기 (특정 지역만: node scripts/export_svgs.js 대전)
```

- `build_data.py`: 경계를 받아 `web/data/base.js`(시도·시군구), `web/data/emd.js`(읍면동)로 저장하고,
  모든 단위 조합(시도↔시군구↔읍면동)의 **인접 관계를 미리 계산**합니다. 50m 이내로 맞닿으면 이웃으로 봅니다.
  바다 건너 섬(제주, 울릉 등)은 맞닿은 지역이 없습니다.
  전남광주통합특별시가 있는 시점이면 광주(29)·전남(46)으로 나눈 시도 경계와 인접표도 함께 만듭니다.
- `export_svgs.js`: 웹 도구와 같은 렌더러(`web/render.js`)로 `svg/`를 만듭니다.

타일 지도는 그릴 지역들의 실제 경계 안에 격자 칸을 깔고(칸 수가 지역 수보다 조금 많아지는 가장 큰 칸 크기), 헝가리안 할당으로 지역마다 실제 위치에서 가장 가까운 칸을 배정합니다(R `geogrid` 패키지와 같은 방식). 전국 시도 타일만 알아보기 쉬운 고정 배치를 씁니다.

좌표는 EPSG:5179(UTM-K)를 10m 격자로 옮긴 값이라 지도가 위아래로 눌리지 않습니다.
