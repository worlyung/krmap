# 비교·보고서 도구

웹 화면의 지도 아래 **비교·보고서 도구**에서 설정합니다. 설정은 **작업 저장** JSON에 함께 들어갑니다. CLI와 MCP도 같은 계산·그리기를 사용합니다.

## 1. 고정 색 구간

`10,20,30`을 입력하면 `10 미만 / 10 이상 20 미만 / 20 이상 30 미만 / 30 이상`으로 나눕니다. 경계는 작은 순서로 최대 8개입니다. 비우면 기존 자동 분류입니다. **묶음 전체에 같은 기준 적용**으로 저장된 장들의 경계값을 맞춥니다. 색 자체까지 동일하게 비교하려면 각 장의 팔레트도 같게 설정하세요.

## 2. 지역 연결과 CSV 양식

**지역명 연결·입력 양식**에 미일치·중복 이름이 표시됩니다. 검색해서 정확한 지역을 선택하고 **연결**을 누르세요. 원본 표는 보존하며 연결 규칙만 작업에 저장합니다. **현재 지도 지역 CSV 양식**은 코드·정식 지역명·빈 값 열을 만듭니다. 엑셀에서 코드의 앞자리 0이 사라지지 않게 텍스트 형식으로 다루세요.

## 3. 전후 비교

표의 숫자 열 두 개를 고르면 같은 크기·색 기준으로 나란히 표시합니다. **증감 지도**는 `이후 − 이전`입니다. 한쪽 값이 없으면 증감도 자료 없음입니다. 비율을 넣었을 때의 차이는 퍼센트포인트이며, 증감률 `(후−전)/전`이 아닙니다. 서로 단위가 같은 열을 선택하세요. 경계는 두 시점 모두 현재 내장 경계이며 과거 경계 변화를 복원하지 않습니다.

## 4. 설명 요소

- 설명 상자: 지역을 선택하거나 가로·세로 비율로 위치를 지정합니다.
- 화살표: 시작·도착 지역을 선택합니다.
- 직선 반경: 실제 지도에서 선택 지역 대표점 주변에 km 단위 원을 그립니다. 도로 이동거리·도달시간이 아닙니다. 범위가 크면 지도 가장자리에서 잘릴 수 있으므로 주변 지역을 함께 표시하세요.

SVG·PNG·PPTX에 반영되며 PPTX에서는 설명 상자·선·원·문구를 편집할 수 있습니다. 반경은 벌린 지도·타일 지도에서는 사용할 수 없습니다.

## 5. 보고서와 내 서식

지도의 오른쪽에 수치가 있는 지역 수, 상위 5개 지역의 값, 설명, 출처를 배치합니다. 비교 지도에서는 이후 열의 수치를 요약합니다. 제안서·성과보고 기본 서식과 **내 서식 저장**을 제공합니다. 내 서식은 보고서 설정·색·글자 크기·비율을 해당 브라우저에 저장하며 원본 데이터를 저장하지 않습니다. 다른 컴퓨터로 작업 전체를 옮길 때는 작업 JSON을 사용하세요.

## 6. xlsx 직접 읽기

10MB 이하 `.xlsx` 파일을 선택하고 시트, 지역 열, 값 열을 지정하세요. 값 열은 Ctrl(macOS에서는 Command)을 눌러 여러 개 선택할 수 있습니다. 첫 6행을 미리 보고 **이 표 사용**을 누릅니다. 첫 행은 열 이름이어야 합니다. 파일은 서버로 업로드하지 않습니다. 수식은 파일에 저장된 계산 결과를 사용하므로 엑셀에서 계산·저장 후 가져오세요. `.xls`·암호화 파일은 지원하지 않습니다.

## 7. 자료 상태

**자료 없음·0·제외 지역 구분**을 켜면 자료 없음은 회색 빗금, 0은 흰색, 분석 제외는 짙은 회색으로 표시하고 범례에 구분을 넣습니다. 빈칸은 0으로 바꾸지 않습니다. 제외한 지역은 색 구간 계산과 요약 수치에서도 빠집니다.

## 8. 연도 슬라이더

연도별로 나란히 놓인 숫자 열을 여러 개 선택한 뒤 적용합니다. 슬라이더·재생 버튼으로 바꿔 보며 모든 시점은 공통 색 구간을 사용합니다. 비교 보기와 연도 보기는 하나씩 적용합니다. SVG·PNG·PPTX는 선택한 시점, HTML은 모든 선택 시점을 저장합니다.

## 9. 독립형 HTML

**독립형 HTML 저장**은 데이터와 지도 그림을 파일 안에 포함합니다. 받은 사람은 별도 설치·로그인·인터넷 없이 브라우저에서 열고 연도 슬라이더를 쓸 수 있습니다. 편집기 전체가 아니라 완성된 지도의 뷰어입니다. 시스템 글꼴에 따라 글자 모양은 달라질 수 있습니다. 자료가 포함되므로 공유 대상을 확인하세요.

## CLI·MCP 설정 예시

```json
{
  "regions": ["대전", "세종", "서울"],
  "hideOthers": true,
  "data": {"table":"지역\t2024\t2025\n대전\t100\t150\n세종\t0\t20\n서울\t80\t60", "by":"2024"},
  "cuts": [20, 100],
  "statuses": true,
  "compare": {"before":"2024", "after":"2025", "difference":true},
  "report": {"title":"성과 요약", "summary":"같은 기준으로 전후를 비교했습니다."},
  "source": "사용자 제공 예시 데이터",
  "formats": ["svg", "png", "pptx", "html"]
}
```

위 내용을 `compare.json`으로 저장한 다음:

```sh
node tools/krmap.mjs render compare.json --out out
```

연도 뷰어는 `compare` 대신 `"timeline":{"columns":["2024","2025"],"index":0}`을 넣습니다.

추가 설정:

```json
{
  "data": {"file":"data.xlsx", "sheet":"실적", "regionColumn":"지역", "valueColumns":["2024","2025"], "by":"2024"},
  "mappings": {"우리 지역":"sido:30"},
  "excluded": ["sido:11"],
  "annotations": [
    {"type":"text", "x":0.1, "y":0.15, "text":"사업 대상 지역"},
    {"type":"arrow", "region":"sido:30", "to":"sido:36", "text":"연결"},
    {"type":"radius", "region":"sido:30", "km":10, "color":"#C23A2E"}
  ]
}
```

지역 키(`sido:30` 등)는 `node tools/krmap.mjs find 대전 --json` 또는 MCP `find_region`으로 확인합니다. `regionColumn`·`valueColumns`는 열 이름 또는 0부터 시작하는 열 번호입니다. `slides` 묶음에서도 `formats:["html"]`로 슬라이더가 있는 HTML 한 파일을 만들 수 있습니다.
