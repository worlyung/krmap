# 데이터 지도·육각형 지도 만들기

## 웹에서 사용

1. 지도 편집에서 지역·단위를 고릅니다. 전국 시군구 또는 한 시도의 읍면동도 가능합니다.
2. 데이터 탭에 CSV를 넣거나 지도 아래 비교·보고서 도구의 엑셀 파일 직접 열기로 `.xlsx`를 읽습니다. 지역 코드 또는 정식 지역명을 쓰고 미일치 항목을 확인하세요.
3. 배경색으로 쓸 열과 색상 범례를 정합니다. 예를 들어 가격을 배경색으로, 후보 A/B 수치를 화살표와 막대로 표시할 수 있습니다.
4. **비교·보고서 도구 → 데이터 화살표·비교 막대그래프**를 엽니다. 화살표 기준 두 열, 색·크기·단위를 정하고, 막대에 쓸 숫자 열 1~6개를 선택한 다음 적용합니다.
5. 전국 시군구·읍면동의 **작은 지역 확대**에서 서울·광역시를 선택하면 확대 창에도 색과 화살표가 표시됩니다. 확대 창은 실제 지도·전국 모드에서 사용합니다.
6. **지도 편집 → 배치 → 육각 타일**로 전환해도 지역별 색과 이름, 연결한 데이터가 유지됩니다. 하나씩 꾸미기에서 타일을 끌면 격자에 맞습니다. 찬 칸은 이동 전 자리로 돌아옵니다. Alt/Option을 누르거나 자동 붙이기를 끄면 자유 이동합니다.
7. 작업 저장은 설정을, SVG·PNG·PPTX 저장은 완성 그림을 저장합니다. PPTX의 막대·화살표·글자는 편집 가능한 도형입니다.

화살표는 첫 열이 크면 왼쪽 위, 둘째 열이 크면 오른쪽 위를 가리킵니다. 길이는 표시 중인 지역의 최대 절댓값 차이에 비례합니다. 방향은 실제 이동 방향을 뜻하지 않습니다. 동률·한쪽 값 없음·제외 지역에는 그리지 않습니다. 비율 차이에는 `%p`, 금액 차이에는 금액 단위를 직접 적으세요. 조밀한 지도는 이름을 숨기거나 화살표 크기를 줄이면 읽기 좋습니다.

막대는 선택한 열 전체에 같은 0 기준과 눈금을 씁니다. 합계를 100%로 재계산하지 않습니다. 빈 값은 자료 없음, 0은 0으로 구분합니다. 음수는 지원하지 않으므로 증감 지도 기능을 사용하세요. 모든 표시 지역을 담기 때문에 지역이 많으면 그림이 길어집니다. 작은 지역 단위는 관심 지역을 골라 저장하는 편이 좋습니다.

육각 지도는 실제 면적·거리·인접 관계를 정확히 보존하지 않습니다. 최대 600개 지역을 지원하며, 전국 읍면동은 지역 범위를 좁혀 주세요. 굵은 시도 경계는 서로 다른 시도의 인접 타일 사이에 표시됩니다.

## Claude Code·Codex·명령줄·MCP

아래 수치는 동작 설명용 가상 자료입니다. `spec.json`으로 저장하고 `node tools/krmap.mjs render spec.json --json`으로 실행합니다. MCP `render_map`의 `spec`에도 같은 설정을 넣습니다.

```json
{
  "regions": ["서울", "부산", "대전", "세종"],
  "hideOthers": true,
  "title": "데이터 지도 예시 · 가상 수치",
  "data": {
    "table": "지역\t가격\t후보 A\t후보 B\n서울\t80\t40\t50\n부산\t30\t60\t30\n대전\t50\t45\t45\n세종\t0\t\t20",
    "by": "가격"
  },
  "infographic": {
    "arrows": {"enabled": true, "first": "후보 A", "second": "후보 B", "firstColor": "#168CCD", "secondColor": "#DB424D", "scale": 1, "unit": "%p"},
    "bars": {"enabled": true, "columns": ["후보 A", "후보 B"], "colors": ["#168CCD", "#DB424D"], "sort": "value", "title": "후보별 비교", "unit": "%"}
  }
}
```

전국 확대 창은 `"nationalUnit":"시군구", "insets":["서울","부산"]`, 육각형은 `"layout":"육각"`을 사용합니다. 숫자 열은 열 이름 또는 내부 열 ID로 지정합니다. 기존 색상 범례·제목·출처 설정을 그대로 함께 쓸 수 있습니다.

## 경계와 자료

내장 지도는 현재 제공되는 행정구역 경계입니다. 선거구가 행정구역을 나누거나 합치는 경우 실제 선거구와 일치하지 않습니다. 이 기능은 선거구 경계 자동 생성·가져오기나 실제 여론조사 수집을 제공하지 않습니다. 선거 시점과 경계 기준이 맞는지 확인하고 자료 출처·조사일을 제목과 출처 칸에 적어 주세요.
